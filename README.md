# SysInfo Tool

Кроссплатформенная CLI-утилита на Python для получения информации о компьютере и сети.

## Вможности
* **ЦП:** модель, ядра, частота, кэш, нагрузка.
* **ОЗУ:** общий объем, занятое место в ГБ и %.
* **Диски:** емкость разделов, свободное место, модели накопителей.
* **Видеокарта:** модель, объем видеопамяти, разрядность.
* **Сеть:** имя хоста, интерфейсы и IP-адреса.
